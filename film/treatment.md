# 按钮，要有回应 · 20 秒知识短片

## 已定方向

用户指定 Lucian UX/UI Prompt 为控件来源，观默 Bento Grid 影片为视觉和动态参考。采用五种同类「按钮微交互」：磁吸、长按、下载、发送、复制。1920×1080，60fps，20 秒；沿用已接受的无旁白、音乐与音效、场景 + 提示词 + 操作演示模式。

核心知识：动效表达状态。让用户知道按钮可操作、操作正在进行、动作已经完成。

## 视觉与运动

语言：modular-grid + continuous-morph + cursor-demo。精确、紧凑、有节拍。7 个固定身份的面板（标题、提示词、5 种按钮）全片连续重排：五个按钮始终保留位置线索，每段将当前按钮扩大为主角。

色板来源：参考片 tokens.json 的黑 #000000、卡片 #161618 / #0f0f11、字 #f5f5f7 / #86868b，主角渐变 #ff8a1f → #ff2d6f → #a63dff。按钮采用 Lucian 的浅色胶囊、蓝青磁吸、红色删除、紫色发送及绿色成功语义。文字 Inter + Noto Sans SC；圆角 32、间距 20、外边距约 100。局部渐变只用于标题卡与主角标记。

## 分镜与节拍

120 BPM，首拍 0 秒，10 小节。主段从 2、5、8、11、14、17 秒进入，均在整数拍；转场为持续重排，不把半小节的位置宣称为小节线。每个按钮先操作，再保留结果阅读时间。

| 时间 | 画面 | 场景 / 可复用 AI 提示词 | 声音 |
|---|---|---|---|
| 0–2 | 第一帧五种按钮已出现；主标题「按钮，要有回应」，面板展开归位 | 5 种按钮微交互 / 场景 + 动作 + 反馈 | 首拍重音；格子归位声 |
| 2–5 | 磁吸按钮升为主角，指针进入、偏移吸附、退出复位 | 主行动入口 / 做磁吸按钮，靠近吸附，离开复位。 | 指针接近轻滑音、回位点击 |
| 5–8 | 删除按钮与文件；按住，红色进度充满，文件收起并显示撤销 | 删除确认 / 做长按删除，1.2秒确认，松开取消。 | 触碰低音、完成短提示 |
| 8–11 | 下载按钮展开为进度条，百分比走满，缩圆打勾，再展开 | 文件下载 / 做下载按钮，显示进度，完成变勾。 | 每段进度细 tick，完成双音 |
| 11–14 | 输入框中的飞机起飞，虚线轨迹，引导消息进入聊天气泡 | 聊天发送 / 做发送按钮，飞机起飞，成功显示回执。 | 呼啸、送达提示 |
| 14–17 | 命令复制，叠纸变勾、成功气泡出现 | 命令复制 / 做复制按钮，成功变勾，并提示已复制。 | 复制点击、短清音 |
| 17–20 | 五种按钮重排汇合；「场景 + 动作 + 反馈」；「每次点击，都值得一个回应。」 | 五项编号名称同时可见 | 主和弦解决；尾音淡出 |

能量：开场 7 → 磁吸 5 → 删除 6 → 下载 9 → 发送 8 → 复制 5 → 总览 4。下载的条 → 圆 → 胶囊形成中段密集变化；发送抛物线为次峰。静止阅读是有意保留，主角外的卡片不做分散注意的无关动画。

连续链：同一 7 个面板从总览→磁吸主角→删除主角→下载主角→发送主角→复制主角→总览；主角缩回缩略卡，下一张从缩略卡放大。标题与提示词留在左侧网格，不压在演示上。

## 验收

九个关键帧，至少两轮改进。检查所有五项都实际出现、提示词完整、长按 1.2 秒成立、按钮结果可读、转场无穿帮、连续跳时的画面一致。逐帧 JPEG，H.264 Main / yuv420p + AAC LC + faststart，完整播放、多个时间点跳转、音频峰值与源码 ZIP 检查。

## 两轮修改

第一轮：提示词字号 32 → 36；长按计时向下取整，避免未满时提前显示 1.2 秒；补充完成状态关键帧。第二轮：标题 / 提示词栏固定在左侧，去掉大卡片左右穿越；转场中缩小交接卡片、短暂降低内容可见度，降低文字交叉遮挡；长按提示词明确 1.2 秒。
